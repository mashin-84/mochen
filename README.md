# 一念飛仙外傳－墨塵傳

橫版動作 RPG（Boss Rush 九關，隻狼式彈刀與架勢），手機橫向遊玩。

- 線上試玩：https://mashin-84.github.io/mochen/
- 上線檔是單檔 `index.html`（Canvas 2D、Web Audio、無外部依賴），由 `src/` 經 `python3 tools/build.py` 組成；素材在 `assets/`。
- 文件：`CLAUDE.md`（開發規則）、`HANDOFF.md`（現況與路線圖）、`STAGE_PIPELINE.md`（單關製作流程）、`docs/`（版本紀錄、設計卡）、`prompts/`（生圖／影片／音效提示詞）。
